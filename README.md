# 맘풀고 웜업 — 배포 가이드

> **오프라인 카드의 맛보기.** 고를 것도 판단할 것도 없이,
> 화면에 뜬 대본을 번갈아 소리 내어 읽는 6턴.

## ⚙️ 배포 3단계

### 1단계 — Netlify 올리기
1. [app.netlify.com/drop](https://app.netlify.com/drop) 접속
2. `netlify` 폴더를 **통째로 드래그 앤 드롭**
3. 생성된 주소 복사 (예: `https://mompulgo.netlify.app`)

### 2단계 — 주소 연결
mampulgo.com 기준으로 이미 설정돼 있습니다. **남은 건 Netlify 주소 한 곳뿐입니다.**
| 파일 | 수정할 곳 | 값 |
|---|---|---|
| 파일 | 항목 | 값 | 상태 |
|---|---|---|---|
| `netlify/assets/config.js` | `WP_BASE` | `https://mampulgo.com` | ✅ 완료 |
| `netlify/assets/config.js` | `HOME_PATH` | `/` | ✅ 완료 |
| `netlify/netlify.toml` | `frame-ancestors` | `mampulgo.com` | ✅ 완료 |
| `wordpress/2-talk-warmup.html` | `NETLIFY_BASE` | Netlify 배포 주소 | ⬜ **배포 후 입력** |

> `1-talk-start.html`은 `window.location.origin`을 쓰므로 수정 불필요합니다.

### 3단계 — 워드프레스 2개 페이지 생성
| # | 슬러그 | 붙여넣을 파일 | 광고 |
|---|---|---|---|
| 1 | `/talk/start` | `1-talk-start.html` | 상·하단 O |
| 2 | `/talk/warmup` | `2-talk-warmup.html` | ✕ |

> 붙여넣기: 페이지 편집 → `+` → **사용자 정의 HTML** 블록 → 파일 내용 전체 복사

## 🎬 사용자 동선

```
/talk/start      애칭 입력 (A/B)
    ↓
/talk/warmup     카드 고르기 → 인트로 → 6턴 읽기 → 완료
    ↓
        [맘풀고 홈으로] 또는 [다른 카드로 한 번 더]
```

완료 시 iframe 내부가 아니라 **부모창 전체**가 홈으로 이동합니다.

### 화면 구성 3가지 장치
| 장치 | 내용 |
|---|---|
| **읽는 시간 확보** | 버튼이 3~9초 잠김. 문장 길이에 비례(글자수÷13)해 자동 계산 |
| **직전 발화 표시** | 상대가 방금 한 말을 화면 위에 남겨 대화가 이어지는 감각 |
| **카드 고르기** | 6장을 펼쳐 직접 선택. 실물 카드를 뽑는 행위와 동일 |

## 🔧 워딩 수정

`netlify/assets/data.js` 한 파일만 고치면 됩니다.

```js
{ who: "B",
  empathy: "{{A}}님 말을 들어보니 정말 걱정되셨나봐요",   // ① 상대 마음 읽기
  mine:    "{{A}}님 말을 들어보니 저는 조금 짜증이나요" }  // ② 내 감정 말하기
```

- `{{A}}` → User A 이름 (원본의 '나리')
- `{{B}}` → User B 이름 (원본의 '딸기')
- 이름이 자동 치환되므로 특정 이름을 직접 쓰지 마세요.
- 1턴은 `empathy: null` (아직 받을 말이 없음)
- `emotions`는 인트로에 표시되는 **실물 카드의 감정 칩**입니다 (선택 기능 아님)

## 📖 규칙카드

오프라인에서 참가자가 **각자 손에 들고 하는 규칙카드**를 웹에서도 재현했습니다.

- 화면 **우하단 `📖 규칙카드` 버튼**으로 언제든 꺼내볼 수 있습니다 (6턴 내내 상시 노출)
- 인트로 하단에도 "규칙카드 먼저 보기" 안내 버튼이 있습니다
- 카드를 탭하거나 「뒤집기」를 누르면 **3D로 앞↔뒤가 뒤집힙니다**

| 면 | 내용 |
|---|---|
| **앞면** | 맘풀고 대화법 — `당신 정말 [상대의 감정] 했겠어요` / `나도 [나의 감정]한 마음이 드네요` |
| **뒷면** | 에니어그램 기반 감정 찾기 — 몸(어깨·배) / 가슴 / 머리 3가지 통로 |

문구 수정은 `netlify/assets/rulecard.js`에서 합니다.

## 👤 이름 · 호칭 처리

진입 페이지에서 입력한 이름이 36개 문장에 자동으로 들어갑니다.
**실제 이름과 호칭을 자동으로 구분**해 '님'과 조사를 붙입니다.

| 입력 | 화면 출력 | 대본 |
|---|---|---|
| 지현 | 지현**님이** 읽어주세요 | **지현님** 말을 들어보니… |
| 엄마 | 엄마**가** 읽어주세요 | **엄마** 말을 들어보니… |
| 여보 | 여보**가** 읽어주세요 | **여보** 말을 들어보니… |
| Michael | Michael**님이** 읽어주세요 | **Michael님** 말을 들어보니… |

- '님'을 생략하는 호칭 목록은 `engine.js`의 `NO_HONORIFIC` 배열에서 관리합니다.
  (엄마·아빠·여보·자기·아들·딸·형·누나·선생님 등 40여 개)
- `우리~`로 시작하거나 `~야`로 끝나는 짧은 애칭도 호칭으로 자동 인식합니다.
- 받침 유무에 따라 조사가 바뀝니다 (엄마**가** / 지현님**이**).

호칭을 추가하려면:
```js
var NO_HONORIFIC = [ "엄마","아빠", /* 여기에 추가 */ ];
```

## 📌 개발 노트 (제외한 기능과 이유)

### 레벨 2·3 (감정 선택 / 공감 랠리)
사람의 감정을 3개 버튼으로 예측해 제시하는 방식에 구조적 한계가 있었습니다.
그 영역은 오프라인 카드가 훨씬 잘 합니다.
웹앱은 **"입을 떼게 만드는 것"** 하나만 담당합니다.

### 진단 리포트
대본을 따라 읽는 훈련이라 **시스템이 수집하는 데이터가 없습니다.**
"버튼을 6번 눌렀다"가 전부인데 이걸로 진단을 하면 빈 칭찬이 되고,
오히려 신뢰를 깎습니다. 그래서 제거했습니다.

### 한 줄 메모
Netlify는 정적 호스팅이라 **DB가 없습니다.** 메모를 받아도 URL로 넘겨
화면에 한 번 보여주고 사라질 뿐, 어디에도 저장되지 않았습니다.
저장되지 않는데 입력을 시키는 건 사용자를 속이는 것이므로 제거했습니다.

> 나중에 저장이 꼭 필요해지면 WP REST API + 인증 + 스팸 방어가 함께 필요합니다.

**현재 이 앱은 어떤 데이터도 서버로 전송하거나 저장하지 않습니다.**

이전 3레벨 버전은 `_archive/mompulgo-v1-3levels/`에 보관돼 있습니다.
